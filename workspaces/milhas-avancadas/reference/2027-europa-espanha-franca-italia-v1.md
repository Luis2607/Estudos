# 2027 Europa: Espanha, França e Itália — Execução v1

## Premissas usadas

- Origem principal: GRU.
- Reposicionamento aceitável se a economia justificar: GIG, FOR, REC, EZE.
- Pessoas: 1 como padrão, recalcular para 2 quando houver dados reais.
- Duração ideal: 16 a 19 dias.
- Janelas sugeridas: abril-maio ou setembro-novembro de 2027.
- Cabine: econômica como base, premium/business como oportunidade se o custo marginal for racional.

## Resultado do loop

A melhor arquitetura inicial é open-jaw:

- Ida: Brasil -> Madrid.
- Volta: Roma ou Milão -> Brasil.
- Miolo: trem/voo interno entre Espanha, França e Itália.

## Plano A: Espanha -> França -> Itália

- Brasil -> Madrid.
- Madrid: 3 noites.
- Barcelona: 3 noites.
- Paris: 4 noites.
- Florença ou Veneza: 2 a 3 noites.
- Roma: 4 noites.
- Roma/Milão -> Brasil.

Por que é o melhor: Madrid é hub forte para entrada via Espanha/Avios/oneworld; Itália é uma saída natural; Paris fica no meio sem obrigar retorno.

## Plano B: França -> Espanha -> Itália

- Brasil -> Paris.
- Paris: 4 noites.
- Barcelona: 3 noites.
- Madrid: 3 noites.
- Florença ou Veneza: 2 a 3 noites.
- Roma: 4 noites.
- Roma/Milão -> Brasil.

Quando usar: se Flying Blue/Smiles/cash abrir oportunidade muito boa para Paris.

## Plano C: Itália -> França -> Espanha

- Brasil -> Roma/Milão.
- Roma: 4 noites.
- Florença ou Veneza: 2 a 3 noites.
- Paris: 4 noites.
- Barcelona: 3 noites.
- Madrid: 3 noites.
- Madrid -> Brasil.

Quando usar: se Star Alliance/ITA/Lufthansa/Aeroplan/LifeMiles abrir melhor disponibilidade para Itália ou se a volta por Madrid ficar muito superior.

## Gateways prioritários

### Entrada Espanha

- GRU -> MAD.
- GIG -> MAD.
- FOR -> MAD.
- REC -> MAD.

Programas a testar: Iberia Plus, British Airways Avios, Qatar Avios, LATAM Pass e opções cash.

### Entrada França

- GRU -> CDG.
- GIG -> CDG.
- FOR -> CDG.

Programas a testar: Flying Blue, Smiles, Air France-KLM e cash.

### Entrada/Saída Itália

- GRU/GIG -> FCO.
- FCO/MXP -> hub Star Alliance -> Brasil.

Programas a testar: Aeroplan, LifeMiles, Miles & More, TAP Miles&Go, Smiles, LATAM Pass e cash.

## Estratégia de busca

1. Buscar primeiro open-jaw cash para ter baseline:
   - GRU -> MAD / FCO -> GRU.
   - GRU -> MAD / MXP -> GRU.
   - GIG -> MAD / FCO -> GIG.
   - FOR/REC -> MAD / FCO -> GRU.

2. Buscar disponibilidade prêmio:
   - AwardFares: multi-airport e multi-date.
   - point.me: comparação cash vs points e instrução de transferência.
   - Seats.aero: alertas e exploração ampla.
   - Sites dos programas: confirmação final.

3. Não transferir pontos antes de confirmar assento real no programa emissor.

## Regras de decisão

A emissão só passa se:

- economia real for maior que custo dos pontos + taxas + voos internos + risco;
- datas forem boas;
- conexão não for absurda;
- trecho longo não for mixed cabin ruim;
- cancelamento/remarcação forem aceitáveis;
- o preço cash não estiver competitivo.

## Deslocamento interno

- Madrid -> Barcelona: trem.
- Barcelona -> Paris: testar trem vs voo low-cost.
- Paris -> Itália: testar voo para Roma/Florença/Veneza/Milão; trem via Milão só se fizer sentido.
- Florença -> Roma: trem.
- Roma -> Nápoles/Costa Amalfitana: opcional se a viagem passar de 18 dias.

## Ordem de monitoramento

1. Iberia/Avios para entrada por Madrid.
2. Flying Blue para entrada/saída por Paris.
3. Star Alliance/Aeroplan/LifeMiles para Itália.
4. Smiles/LATAM/TudoAzul como comparativo brasileiro.
5. Cash fare sempre como baseline.

## Conclusão v1

Plano mais forte no momento: Brasil -> Madrid, roteiro terrestre/aéreo por Espanha e França, Itália no final, volta por Roma ou Milão.

A próxima execução deve acontecer quando houver mês escolhido e quantidade de pessoas, porque isso muda disponibilidade, hotel e custo real.
