# Notes

## Learning and execution preferences

- Prioritize immediate practical application before deeper theory.
- Use Claude Code or Codex as execution environments; GPT remains strategic and personal support.
- Obsidian/wiki is the long-term memory and project brain. Retrieve only the context relevant to the active task instead of loading the entire vault.
- For frontend and UI work, use visual references as the primary source of truth: screenshots, recordings, Figma mockups and interaction examples.
- Before implementation, the agent should interview Luis to close meaningful gaps in intent, behavior, states, transitions and edge cases.
- Define success before the loop starts. Include visual and behavioral verification through browser tools when available.
- Prefer before-and-after visual evidence over long textual audit reports.
- A loop refines implementation against a reference; it does not replace human design judgment.
- Respect the existing design system. Check the design-system knowledge base before creating components or variants. Prefer reuse.
- Include heuristic review with severity and concrete evidence in design audits.
- Require human approval before shared or externally visible changes.
